# 《Monsteria》现有玩法总结与更新计划

更新时间：2026-08-11
项目类型：爬塔路线选择 + 商店构筑 + 自动战斗

## 一、现有玩法总结

### 1. 单局核心流程

当前游戏已经具备一套能够运行的爬塔自走棋基础循环：

1. 从主菜单开始新游戏。
2. 进入爬塔地图。
3. 从当前节点连接的路线中选择下一个节点。
4. 根据节点进入备战、战斗、商店、事件、宝箱或休息内容。
5. 购买怪兽、调整阵容、激活羁绊并配置道具。
6. 进入自动战斗。
7. 胜利后获得金币、道具等奖励并继续爬塔。
8. 失败后扣除生命，生命耗尽则本局结束。
9. 击败当前地图的 BOSS 后完成远征。

游戏现在应以“区域、层数和路线节点”表达进度，不再使用“第几天”和“1/10 进度”的旧设计。

### 2. 备战与商店

- 队伍最多放置 6 只怪兽。
- 备战席最多放置 4 只怪兽。
- 新游戏时队伍和备战席为空。
- 购买怪兽时优先进入队伍，队伍满后进入备战席。
- 支持刷新和锁定商店。
- 商店会按品质概率抽取怪兽、道具和饰品。
- 支持拖动换位、队伍与备战席互换以及出售怪兽。
- 相同怪兽可以合成：
  - 3 个一星合成二星。
  - 9 个一星总量合成三星。
- 一星、二星和三星分别使用白色、绿色和红色等级文字。
- 商店卡牌支持悬停抖动和详细信息浮窗。
- 队伍与备战席角色支持缓慢摇摆和选中缩放动画。
- 怪兽卡会显示生命、特殊属性、元素和种族标签。

### 3. 怪兽与羁绊

每只怪兽当前拥有：

- 元素标签。
- 种族标签。
- 品质。
- 生命、攻击、充能等战斗属性。
- 近战或远程定位。
- 星级。

目前已有 9 类羁绊：

- 自然
- 火
- 雷
- 岩
- 植物
- 虫群
- 龙族
- 机械
- 亡灵

羁绊栏能够统计上阵怪兽数量，并在鼠标悬停时显示不同档位的效果。部分羁绊已经接入战斗，包括：

- 治疗。
- 燃烧。
- 闪电。
- 护甲。
- 减速。
- 复活。
- 吸血。
- 充能。
- 溅射。

### 4. 战斗系统

- 战斗采用最多 6 对 6 的自动战斗形式。
- 我方位于左侧两排。
- 敌方位于右侧两排，并镜像朝向左侧。
- 角色会根据近战、远程和前后排规则选择目标。
- 每个角色拥有技能进度条，充满后自动释放技能。
- 已支持伤害、治疗、护盾、减速、燃烧、复活和吸血等效果。
- 已有共享的远程投射物表现。
- 敌人数量和数值会根据地图位置及节点类型增加。
- 胜利会获得金币，部分战斗会掉落道具。
- 失败会扣除生命。
- 支持战斗倍速和战斗内设置。

### 5. 地图与节点

当前地图包含 23 个节点，并支持分支路线。

已有节点类型：

- 起点。
- 普通战斗。
- 精英战斗。
- 商店。
- 随机事件。
- 宝箱。
- 休息。
- BOSS。

地图支持：

- 左右拖动浏览。
- 只能选择相邻的可达节点。
- 节点解锁与已完成状态。
- 角色沿路线移动。
- 随机事件选项及即时奖励。
- BOSS 完成后的远征结算。

### 6. 道具与饰品

- 消耗品可以提供金币或下一场战斗加成。
- 饰品可以提供本轮持续生效的属性加成。
- 背包支持道具和饰品分类。
- 支持滚动浏览和使用消耗品。
- 道具图标已进行统一整理。

### 7. 图鉴与训练家

- 图鉴包含怪兽、饰品、道具和训练家分页。
- 没有见过的怪兽会使用“？”隐藏图片和名称。
- 初始奖杯、勋章和星标为黑色，达到条件后才解锁。
- 怪兽详情支持等级切换、标签、能力和技能说明。
- 当前已经放入 3 名训练家。
- 训练家目前主要用于展示，还没有成为可选择的玩法系统。

### 8. 主菜单与设置

- 已有启动 Logo 动画、黑幕展开和任意键继续。
- 启动动画可以跳过。
- 主菜单包含开始、继续、设置、更新规划和退出。
- 已有背景音乐、音效和音乐音量控制。
- 设置菜单已有全屏、分辨率、音效、音乐、语言和按键布局外观。
- UI 使用思源黑体 Heavy 或指定像素字体，并配置描边和阴影。

## 二、当前缺少的部分

### P0：游戏循环问题（已于 2026-08-11 完成）

本轮已经完成初始金币、起点/首战、旧进度字段、多层爬塔、本地存档和自动测试修复。以下条目保留为修复记录与回归测试依据，不再计入剩余开发量。

#### 1. 初始金币不符合设计

当前代码中的初始金币为 5，已经确定的设计要求为 8。

#### 2. 起点和首战逻辑错误

当前起点会进入备战并触发一次战斗，但首战识别要求“第 0 列必须是战斗节点”。实际第 0 列是起点，真正的战斗节点从第 1 列开始。

这会造成：

- 首战宝箱无法正常触发。
- 首战单敌人难度无法生效。
- 起点战斗与正式首战的定义冲突。

#### 3. 旧版天数设计没有清理干净

当前仍保留：

- day 状态。
- progress 状态。
- “第 1 天 · 战斗”等旧文本。

这些内容需要全部移除或迁移为区域与层数信息。

#### 4. 没有真正的多层爬塔

当前只有一张固定地图，击败 BOSS 后直接显示远征完成，尚未支持：

- 当前层数。
- 当前区域。
- 多层连续生成。
- 区域之间切换。
- 普通层、精英层和首领层节奏。
- 最终通关条件。

#### 5. 没有本地存档

“继续游戏”目前只依赖程序内存。关闭游戏后无法恢复：

- 地图种子。
- 当前区域、层数和节点。
- 已完成节点。
- 金币和生命。
- 队伍、备战席和怪兽星级。
- 道具和饰品。
- 本轮加成。
- 图鉴与成就状态。
- 设置选项。

#### 6. 自动测试部分失效

- 合成测试仍使用旧版售罄图案旋转方向。
- 道具测试在 Godot 4.7 下存在类型推断错误。
- 部分视觉测试只能在真实渲染模式运行。
- 战斗退出存在资源未释放警告。

### P1：战斗深度不足

- 敌方主要使用固定阵容。
- 精英和 BOSS 主要依靠数值提升，缺少专属机制。
- 怪兽独立技能数量不足，角色差异不明显。
- 缺少统一的攻击间隔、射程、技能目标和状态效果数据。
- 升星后的属性和技能成长规则还不完整。
- 羁绊与道具、复活和升星之间缺少完整组合测试。
- 战斗中的暴击、护盾、治疗和羁绊触发反馈不足。

### P2：构筑与经济不足

- 怪兽数量不足以支持长期爬塔和多种构筑。
- 商店品质概率不会随爬塔层数形成完整成长。
- 没有完整的共享卡池、抽空和回收规则。
- 道具与饰品大多使用程序生成名称和数值效果。
- 缺少能够改变战斗方式的机制型装备。
- 缺少道具品质、掉落池、叠加上限和互斥规则。
- 经济数值尚未经过系统平衡。

### P3：地图内容不足

- 地图仍是固定的单区域布局。
- 缺少楼层生成、区域切换和多种路线结构。
- 随机事件数量较少。
- 事件缺少条件选项、连续事件和风险回报。
- 商店、休息、宝箱等非战斗节点差异不够明显。
- 缺少区域专属敌人、背景、事件和 BOSS。

### P4：局外成长不足

- 训练家没有开局选择和被动技能。
- 图鉴解锁没有形成完整奖励循环。
- 奖杯、勋章和星标的条件没有正式定义。
- 缺少最高层数、通关次数和历史阵容记录。
- 缺少新怪兽、道具、训练家和难度的局外解锁。

### P5：设置与发布质量不足

- 设置不能持久保存。
- 语言和按键布局目前主要是界面展示。
- 缺少手柄导航和按键重绑定。
- 项目视口、输出分辨率和玩法坐标不统一，存在字体模糊风险。
- 缺少统一测试入口和自动构建。
- 缺少完整的新手引导、操作说明和发布文档。

## 三、分版本更新计划

## v0.2：修复并锁定基础循环（已完成）

目标：让现有单张地图流程稳定、逻辑正确。

### 开发内容

1. 初始金币改为 8。
2. 明确起点只负责进入初始备战。
3. 修复首战识别、首战敌人数量和首战宝箱。
4. 移除全部 day、progress 和天数文本。
5. 修复失败重试、返回地图和 BOSS 结算边界。
6. 修复现有自动测试。
7. 处理战斗退出资源警告。
8. 统一 1920×1080 显示标准和字体渲染。

### 验收标准

- 能完整完成“新游戏 → 备战 → 战斗 → 路线 → BOSS → 结算”。
- 初始状态、奖励和生命变化完全正确。
- 所有界面不再出现天数和 1/10 进度。
- 全部核心自动测试通过。

## v0.3：建立真正的多层爬塔（已完成）

完成日期：2026-08-11。当前采用 9 层、3 区域结构；每个区域第 3 层为区域 BOSS。每层会生成新的节点类型与路线连接，敌人数值、商店品质概率及金币事件奖励随楼层成长，并支持自动存档、继续游戏和二次确认删除存档。

目标：从单张地图升级为可以持续推进的爬塔模式。

### 开发内容

1. 新增正式的爬塔运行状态：
   - 随机种子。
   - 当前层数。
   - 当前区域。
   - 当前节点。
   - 已完成节点。
   - 地图节点及连接。
2. 每个区域包含若干普通层和一个区域 BOSS。
3. 击败 BOSS 后进入下一区域。
4. 根据层数生成节点和路线。
5. 敌人数值、商店概率和奖励随层数成长。
6. 增加失败结算和最终通关结算。
7. 添加自动保存、继续游戏和删除存档。

### 验收标准

- 一局可以连续经历多个楼层和区域。
- 关闭游戏后可以准确恢复当前对局。
- BOSS 胜利后能够正确进入下一区域。
- 生命耗尽后能够生成完整失败结算。

## v0.4：扩充怪兽和战斗

目标：让不同怪兽与羁绊形成明显不同的战斗体验。

### 开发内容

1. 将怪兽属性迁移到独立数据资源。
2. 为每只怪兽定义：
   - 基础属性。
   - 攻击距离。
   - 攻击间隔。
   - 技能目标规则。
   - 独立技能效果。
   - 升星成长。
3. 建立按区域、层数和节点类型划分的敌方阵容池。
4. 为精英和 BOSS 制作专属技能与阶段机制。
5. 完善状态效果系统和战斗提示。
6. 完成全部羁绊的自动测试和第一轮平衡。

### 验收标准

- 不同区域能遇到明显不同的敌方阵容。
- 每只怪兽至少拥有一项可辨识的核心技能。
- 精英与 BOSS 不再只是高数值普通敌人。
- 羁绊说明、实际数值和战斗表现一致。

## v0.5：完善经济、道具和地图事件

目标：让路线选择、金币管理和奖励取舍成为核心策略。

### 开发内容

1. 增加随层数变化的商店等级和品质概率。
2. 建立共享卡池、售罄和回收规则。
3. 正式设计道具及饰品：
   - 品质。
   - 掉落来源。
   - 叠加规则。
   - 互斥规则。
   - 机制型效果。
4. 扩充事件库。
5. 支持条件选项、连续事件和风险回报。
6. 强化休息、宝箱、商店和精英节点的独特作用。
7. 增加不同区域的地图与场景主题。

### 验收标准

- 玩家每层都需要在刷新、购买、保存金币和路线奖励之间做选择。
- 道具不再只是统一的数值加成。
- 不同路线具有明显的风险和收益差异。
- 连续多局时事件和敌人组合不会高度重复。

## v0.6：训练家与局外成长

目标：让每次失败或通关都能积累记录，并提供新的开局选择。

### 开发内容

1. 将训练家变为开局可选角色。
2. 为每名训练家增加专属被动、初始奖励和解锁条件。
3. 完成怪兽、道具、饰品和训练家图鉴存档。
4. 正式定义奖杯、勋章和星标的解锁条件。
5. 增加最高层数、通关次数和历史阵容统计。
6. 通过成就解锁新怪兽、道具、训练家和高难度模式。
7. 增加完整的通关与失败统计界面。

### 验收标准

- 不同训练家能够明显改变开局策略。
- 图鉴和成就在重启游戏后仍然保留。
- 通关或失败时能展示本局路线、阵容和解锁内容。

## v0.7：演示版打磨

目标：形成一个可以稳定发布的完整 Demo。

### 开发内容

1. 保存并实际应用全部设置。
2. 完成键鼠与手柄导航。
3. 增加按键重绑定。
4. 完善战斗、地图和 UI 音效及动画。
5. 增加新手引导和辅助功能。
6. 建立统一测试入口和关键流程回归测试。
7. 配置 Windows 导出、版本号、README 和发布说明。

### 验收标准

- 只使用键盘或手柄也能完成整局游戏。
- 设置在重启游戏后仍然生效。
- 新游戏、继续游戏、通关、失败和退出流程均无阻断问题。
- 可以生成一份可直接分发的 Windows 演示版。

## 四、推荐执行顺序

1. 先完成 v0.2，修正当前游戏循环。
2. 再完成 v0.3，建立多层爬塔和存档。
3. 然后完成怪兽数据化、独立技能和敌方阵容池。
4. 接着扩充道具、事件、商店和区域内容。
5. 最后接入训练家、局外成长、完整设置和发布流程。

当前最适合作为下一项开发任务的是：

> 扩充敌方阵容池，给精英和 BOSS 增加专属机制，并对新增怪兽的品质、射程、属性和独立技能进行第一轮实战平衡。
